# Movie Recommendation System

This project applies **AI techniques** to recommend movies based on similarity in genres, keywords, cast, and crew. It implements **TF-IDF** and **Cosine Similarity** for recommendation.

## Features

- **Content-Based Filtering**: Suggests movies based on metadata.
- **Text Processing**: Extracts key features from movie descriptions.
- **Similarity Computation**: Uses **Cosine Similarity** for accurate recommendations.
- **Example Testing**: Tested with movies like *Avatar* and *Batman Begins*.

## Technologies Used

- **Python**
- **NumPy**, **Pandas**
- **Scikit-Learn**
- **NLTK** (for Natural Language Processing)
- **Streamlit** (for future web deployment)
- **Heroku** (for future hosting)

## Installation & Usage

1. Clone the repository:

   git clone https://github.com/yourusername/Movie-Recommendation-System.git
   

2. Navigate to the project directory:
   
   cd Movie-Recommendation-System
   

3. Install dependencies:
   
   pip install -r requirements.txt
   

4. Run the recommendation script:
   ```bash
   python recommend.py
   ```
